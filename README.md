
# 📱 GiveNGet — Flutter

**GiveNGet** is a community donation marketplace built with **Flutter**.  
Post items you no longer need, discover free items nearby, mark favorites, and message donors to express interest. Donors can review requests and accept a recipient — simple, safe, and kind.

---

## ✨ Features

- **Onboarding flow** that explains the mission and gets users started quickly  
- **Email/password auth** (Sign Up, Login, Forgot Password)  
- **Explore feed** with categories, search, and card grid layout  
- **Post a donation** with photos, category, condition, and location  
- **Item details** with availability, badges, and gallery  
- **“Interested” messaging** — send a short note to the donor  
- **Donor inbox** to review interested users and **Accept/Decline**  
- **Favorites** and **Profile** tabs for fast access and management
